# THE BASE INTERNATIONAL

This repository contains a simple static website for "THE BASE INTERNATIONAL".

Live site
- You can publish the site using GitHub Pages. In the repository settings go to "Pages" and choose the `main` branch and the `/ (root)` folder. The site will be available at `https://PAUL111111111.github.io/PAUL111111111/` after it finishes building.

Email / Contact
- The contact section is wired to the email address `thebaseinternational@gmail.com`.
- The contact form uses a `mailto:` link which opens the visitor's email client, pre-fills the subject and body, and addresses the message to the configured email. No server is required.

Next steps / Suggestions
- If you want form submissions captured without requiring the user's email client, integrate a service such as Formspree, Netlify Forms, or add a server endpoint.
- Add social links, logos, images in an `assets/` folder and update the HTML.

Deployment
- Optionally add a GitHub Action to build/deploy if you use a static site generator.
